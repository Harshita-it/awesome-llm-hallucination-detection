# GitHub Implementations

Existing repositories implementing methods discussed in the research paper.

- **semantic_uncertainty (Farquhar et al.)**
  [GitHub](https://github.com/jlko/semantic_uncertainty)
  Official implementation accompanying "Detecting Hallucinations in Large Language Models Using Semantic Entropy" (Nature, 2024). Directly implements the semantic entropy method central to the paper.

- **SelfCheckGPT**
  [GitHub](https://github.com/potsawee/selfcheckgpt)
  Implements black-box, sampling-based hallucination detection using self-consistency across generations.

- **LM-Polygraph**
  [GitHub](https://github.com/IINemo/lm-polygraph)
  Implements a broad set of uncertainty quantification methods (entropy-based, ensemble-based, density-based) for LLMs, useful for comparing token-level vs. semantic approaches.

- **semantic-entropy-probes**
  [GitHub](https://github.com/OATML/semantic-entropy-probes)
  Companion implementation for Kossen et al. (2024)'s hidden-state-based semantic uncertainty probes.

- **truthfulqa**
  [GitHub](https://github.com/sylinrl/TruthfulQA)
  Official benchmark code for TruthfulQA, useful for evaluating whether uncertainty correlates with factual correctness.
